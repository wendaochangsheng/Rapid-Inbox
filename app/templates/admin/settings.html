运行参数

SMTP 接收策略

这些参数会写入 system_settings，并在当前运行进程中立即生效。

域名收件模式

任意域名模式会把未知域收入私有隔离策略，不会默认公开。

任意域名访问策略

默认完全私有。只有明确勾选后，未知域邮箱才可从对应公共入口查阅。

任意域名保留天数

0 表示永久；大于 0 时，每条投递独立计算到期时间。

最大邮件大小

单位为字节。超过此值的邮件会被拒收。

单封邮件最大收件人数

超出后该封邮件会被拒收。

SMTP 空闲超时（秒）

连接空闲超过此秒数会被服务器关闭。

SMTP 并发连接上限

设为 0 表示不限制并发连接数。

每 IP 短窗口连接上限

超过窗口阈值的 IP 会被暂时拒绝建立连接。

SMTP 连接限流窗口（秒）

配合上方"每 IP 上限"计算时间窗口。

磁盘告警阈值（%）

磁盘占用超过此百分比时会触发告警。

清理间隔（秒）

后台扫描到期投递与待删除文件的周期。

SMTP 会话保留（秒）

已结束的网络会话超过该时间后分批清理。

空邮箱保留（秒）

最后一条投递删除后，空邮箱元数据继续保留的时间。

指标保留（秒）

预聚合邮件指标的保留时间。

审计日志保留（天）

安全审计日志分批清理前的最短保留期。

清理批次大小

限制单次事务规模，降低高吞吐收件期间的写锁停顿。

文件 GC 批次大小

每轮处理的持久化文件删除任务数，失败会指数退避重试。
